# C Day 92 - Inventory Management System

## About
A C application for managing product records and inventory stock.

## Features
- Add products with unique IDs
- View inventory
- Search products by ID
- Update stock quantities
- Calculate total inventory value
- Save records in a text file

## Files
- `inventory.c` - Main program
- `products.txt` - Sample inventory data

## Compile and Run
Compile:

`gcc inventory.c -o inventory`

Windows:

`inventory.exe`

Linux:

`./inventory`

## Data Format
Each line of `products.txt` contains:

`ID Name Quantity Price`

Product names must be single words in this version.

## Concepts
Structures, arrays, functions, file handling, searching, and calculations.
